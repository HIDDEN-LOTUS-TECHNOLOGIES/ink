Merge IDs + traits

Pair an ids file with a traits file and download the collection. Everything stays in this browser. Nothing is signed or submitted.

Same files as the Metadata Kit. A chosen file is used instead of the paste box. When a row has no name, the item number is the name.

Ids

One inscription id per line, a JSON array of ids, or a JSON array of objects with an id. A first line that says id is a header and is skipped. Blank lines are skipped. Each remaining row keeps its place.

Traits

A CSV with a header, a JSON array, or a JSON object keyed by inscription id or by number. Rows with inscription ids join on that id. Otherwise rows join by number, or by order, and the report says which.
