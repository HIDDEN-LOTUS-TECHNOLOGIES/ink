Batch inscription cost

Pick one or more files. This page builds one ord wallet batch: one commit and one reveal carrying every file. The 400,000 weight-unit cap applies to that reveal. A file that cannot fit alone is named and left out. A batch that is over the cap is split.

Estimate only. Nothing is signed or broadcast.

Formula

ord wallet batch makes one commit and one reveal. The commit is one P2TR key-path input and two P2TR outputs, 154 vbytes, however many files are in the batch. The reveal script is one 32-byte placeholder and OP_CHECKSIG, then every file's envelope: OP_FALSE OP_IF "ord", the content type, and the body in pushes of 520 bytes. This estimate uses separate-outputs, so the reveal pays one postage output per file. The placeholder is only there so the script is the right length. No key is created.

witness bytes = 1 + 65 + compact size of the script + script + 34

reveal weight = non-witness weight of one input and one output per file + witness bytes

reveal vbytes = ceil(reveal weight / 4)

Witness bytes count once toward weight. Bytes outside the witness count four times. Virtual size is ceil(weight / 4). Bitcoin Core will not relay a transaction over 400,000 weight units, and ord refuses that reveal unless --no-limit is used. 390,000 weight units should be safe. A batch over 400,000 weight units is split into more than one commit and reveal.

batch sats = ceil(commit vbytes × sat/vB) + ceil(reveal vbytes × sat/vB) + postage outputs

Postage defaults to 10,000 sats per output, ord's TARGET_POSTAGE. 546 sats is the dust floor. Changing postage changes the sats locked in each reveal output. It does not change the virtual size. A fractional sat/vB is rounded up once on the commit and once on the reveal of each batch, then the batches are added. Recommended rates are the mainnet fastestFee, halfHourFee, hourFee, and economyFee from mempool.space. The custom sat/vB applies to every batch. The optional USD line uses /api/v1/prices on the same host. Either request can fail and the size estimate still stands.

Reads /api/v1/fees/recommended and /api/v1/prices on mempool.space. No wallet, no keys, no signing, no broadcast.
