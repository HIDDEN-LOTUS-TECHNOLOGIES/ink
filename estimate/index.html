Inscription cost

Pick a file or type text. This page builds the ord envelope in the browser and estimates the mainnet commit and reveal. A chosen file is used instead of the text box. The limit is 390 KB, the same as the signet lab.

Estimate only. Nothing is signed or broadcast.

Formula

The commit estimate is one P2TR key-path input and two P2TR outputs, the commit output and a change output.

commit vbytes = ceil(10.5 + 57.5 + 43 + 43) = 154

10.5 is the version, the locktime, the input and output counts, and the segwit marker and flag (2 witness bytes / 4). 57.5 is one P2TR key-path input: 41 non-witness bytes plus a 66-byte witness. 43 is one P2TR output, counted twice.

The reveal estimate is one P2TR script-path input and one P2TR output paying the postage. Postage defaults to 546 sats. Changing it changes the sats you lock in the inscription output. It does not change the virtual size.

witness bytes = 1 + 65 + compact_size(script) + script + 34

reveal weight = 378 + witness bytes

reveal vbytes = ceil(reveal weight / 4)

The witness is a 64-byte Schnorr signature, the envelope script, and a 33-byte control block (leaf version plus a 32-byte internal key, one leaf so there is no merkle path). 378 is the weight of the version, locktime, counts, the outpoint, the empty scriptSig, one P2TR output, and the segwit marker and flag.

The envelope script is the same shape the signet lab builds with micro-ordinals: a 32-byte x-only key, OP_CHECKSIG, then OP_FALSE OP_IF "ord", tag 1, the content type, OP_FALSE, the body, and OP_ENDIF. The body is pushed in chunks of 520 bytes. The key bytes on this page are a placeholder. Their length is what matters, and no key is created.

Witness discount: bytes outside the witness count as 4 weight units each. Witness bytes count as 1. Virtual size is ceil(weight / 4), so the inscription body, which lives in the witness, is charged at one quarter of a non-witness byte.

commit fee = ceil(commit vbytes × sat/vB)

reveal fee = ceil(reveal vbytes × sat/vB)

total sats = commit fee + reveal fee + postage

Recommended rates are the mainnet fastestFee, halfHourFee, hourFee, and economyFee from mempool.space. The optional USD line uses /api/v1/prices on the same host. Either request can fail and the size estimate still stands.

Reads /api/v1/fees/recommended and /api/v1/prices on mempool.space. No wallet, no keys, no signing, no broadcast.
