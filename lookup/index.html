Inscription lookup

Paste an inscription id. The page reads its number, content type, metadata traits, parents, children, and content from ordinals.com, then asks mempool.space about the reveal transaction. Nothing is written to Bitcoin.

Reads /r/inscription, /r/metadata, /r/children, /r/parents, and /content on ordinals.com. Metadata hex is CBOR, decoded here. mempool.space fees and the reveal transaction are skipped if that request fails.
