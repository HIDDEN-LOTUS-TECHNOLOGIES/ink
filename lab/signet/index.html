Signet inscribe

A proof that an inscription can be built, signed, and broadcast with no ord node. The browser talks only to the public mempool.space signet API. Fund it with a throwaway key or a signet wallet. No mainnet.

1. Funding

Use a throwaway key kept in this browser, or connect a signet wallet. The reveal is always signed by a one-time key on this page. The wallet only signs the commit, and it does not broadcast.

This address is generated in the browser and kept in localStorage. Send signet coins to it from a faucet, then come back.

Signet faucet Alt faucet

Pick a wallet. Xverse funds the commit from the payment address and receives the inscription on the ordinals address. UniSat uses one address for both. The wallet has to be on Signet. If it is not, the page tells you how to switch.
